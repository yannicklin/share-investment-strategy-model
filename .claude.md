## 📚 Domain Language (From CONTEXT.md)

| Term | Means | Example |
|------|-------|---------|
| **Strategy** | Trading rule or algorithm | "Buy undervalued large-caps, hold 6 months" |
| **Backtest** | Historical simulation with fees/taxes | 10 years ASX data, -$5k brokerage fees included |
| **Signal** | BUY/SELL/HOLD recommendation | Generated by model at each decision point |
| **Model** | AI algorithm for prediction | Random Forest, LSTM, Prophet, CatBoost, NGBoost |
| **Consensus** | Multi-model voting outcome | 3/5 models vote BUY → signal is BUY |
| **Hurdle Rate** | Minimum acceptable return | 8% annual (fees + tax + risk buffer) |
| **Warmup Period** | Historical data before backtest | 90 days to prime indicators (LSTM, moving averages) |
| **Win Rate** | % of trades with positive return | 55% (55 winning, 45 losing trades) |
| **Sharpe Ratio** | Risk-adjusted return | >1.0 is good (1.25 = excellent) |
| **Max Drawdown** | Largest peak-to-trough loss | -25% (worst drawdown during backtest period) |

**Always use CONTEXT.md to decode terminology.**

## 🔍 Code Review Checklist

When running `/code-review`, verify:

### Standards
- [ ] Naming follows Python conventions (snake_case for functions/variables)
- [ ] No hardcoded values (use config.py)
- [ ] Error messages are clear
- [ ] Functions under 50 lines
- [ ] Docstrings on public methods
- [ ] Type hints on function signatures
- [ ] No commented-out code
- [ ] No debug print statements

### Spec Compliance
- [ ] Implements acceptance criteria from original spec
- [ ] Doesn't change existing backtest logic (regression test?)
- [ ] Handles edge cases mentioned in spec (thin data, holidays, splits)
- [ ] Fee/tax calculation is correct
- [ ] Warmup period applied correctly
- [ ] Validation logic is auditable

### Financial Accuracy
- [ ] All trades account for brokerage fees
- [ ] Tax-aware hurdle rate calculation (if applicable)
- [ ] P&L calculation matches manual verification
- [ ] Equity curve is monotonic (tracking correctly)
- [ ] No division by zero in metrics (Sharpe ratio, etc.)
